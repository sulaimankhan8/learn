## 🛠️ The 8-Step Learning Cycle

Every single topic follows this strict learning workflow:

1. **Concept (The "Why")**: Why it exists, problem solved, operating system mechanics.
2. **Diagram**: Visualizing kernel/host/container boundaries and data flows.
3. **Example**: Simplest clean working reproduction.
4. **Hands-on Task**: You execute, inspect, and analyze runtime behavior.
5. **Break & Debug**: Deliberately inject failures (OOM, port conflicts, volume detachment, DNS drops).
6. **Challenge**: Scenario-based problem without immediate answers.
7. **Real-world Application**: How this exact concept manifests in AWS ECS, GCP Cloud Run, K8s, and production pipelines.
8. **Review & Interview Prep**: Senior-level architectural questions & mental models.
